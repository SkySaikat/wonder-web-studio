# Wonderweb content, indexing and hero work — 11 November 2026

## 1. Indexing
- Check production robots, HTTP headers, canonicals, sitemap and image access.
- Inspect the current Google Search Console and Bing reports; distinguish old errors from live blockers.
- Preserve preview noindex, enable production indexing, and repair any actual blocked or missing resource.
- Validate image discovery and sitemap consistency. Search engines decide whether and when eligible URLs are indexed.

## 2. Source audit and migration
- Inventory every WordPress post/page, its status, original date, content and links.
- Exclude drafts, trashed items, empty templates, redundant landing pages, old legal/company material and unsupported claims.
- Retain useful editorial material, adapt the service voice, strip WordPress scripts/forms/styles and remove unrelated company identity or proof.
- Map source internal links to relevant Wonderweb destinations; retain useful external references.
- Record original source dates separately from the date of the Wonderweb adaptation. Show this distinction to readers.
- Future source items remain scheduled and unavailable until their actual publication time; do not insert future dates into currently public pages.
- Add crawlable HTML, metadata, schema, image covers, internal discovery links and Markdown equivalents for migrated material.
- Record every migrated, consolidated or held item in a reviewable manifest.

## 3. Hero
- Create an original blue/pink/lilac flowing background with fine grain, based on the supplied reference.
- Use a separate optimized image so pricing/FAQ art is unaffected.
- Follow the supplied mobile composition: badge, corner arrow, clear space, heading and two calls to action.
- Check desktop, mobile, readability and reduced-motion behavior.

## 4. Validation and delivery
- Run meaningful migration/date/link tests, type check and production build.
- Verify representative pages and discovery endpoints in a browser and through HTTP.
- Document what is live, what is local, and any account access or search-engine processing still required.
